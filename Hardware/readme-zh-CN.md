# 硬件文档 - ArmSync 6-DOF 机械臂

本目录包含 ArmSync 六自由度机械臂项目的所有硬件相关文件。

[English Document](/Hardware/readme.md)

## 项目简介

ArmSync 是一款采用双 IMU 主从无线遥操作控制的六自由度机械臂。本项目注重成本效益和易于复现。

### 主要规格

| 参数 | 数值 |
|-----------|-------|
| 自由度 | 6 (J1-J6) |
| 臂展（含夹爪） | ~610mm |
| 末端负载 | 350g（目标） |
| 控制接口 | CAN 总线 / 舵机信号 |
| 电源 | 24VDC(步进电机) / 5VDC(舵机) |

### 关节配置

| 关节 | 名称 | 电机 | 减速比 | 功能 |
|-------|------|-------|------------|----------|
| J1 | 基座旋转 | 57×76mm 步进电机 | 20:1 | 基座旋转 |
| J2 | 肩部俯仰 | 42×60mm 步进电机 | 30:1 | 肩部上下 |
| J3 | 肩部偏航 | 42×40mm 步进电机 | 10:1 | 肩部左右 |
| J4 | 肘部 | 42×48mm 步进电机 | 10:1 | 肘部弯曲 |
| J5 | 腕部俯仰 | 42×40mm 步进电机 | 10:1 或 5:1 | 腕部上下 |
| J6 | 腕部旋转 | 42×34mm 步进电机 | - | 腕部旋转 |
| EE | 夹爪 | MG90S 舵机或任意其他末端执行器 | - | 末端执行器 |

## 快速开始

### 1. 查看设计

查看 [3D Files](./3D%20Files/) 目录获取完整机械设计文件：
- **SolidWorks 2026/**: 原始可编辑源文件
- **STEP and STL/**: 通用格式，用于查看和打印
- **3MF for printing/**: 预配置的 Bambu Studio 项目文件
- **URDF/**: 可用于 ROS 等的机械臂建模、仿真

查看 [PCB 原理图和Layout](./PCBs/) 目录，了解需要用到的板子文件。
- **EasyEDA_LCEDA/**: 包含遥控器PCB，可穿戴IMU传感器PCB，以及Renesas CPKHMI-RA8P1 板子的扩展板文件。
- **Imgs/**: 一些原理图和PCB板子截图。
- **KiCad 10/**: 包含电机CAN总线/舵机控制线连接器板子。此板子被设计于插在每个 ZDT 步进电机控制器的接口上，做到线路中继。

### 2. 采购零件

参见 [Parts BOM.md](./Parts%20BOM.md) 获取完整零件清单，包括：
- 电机规格及价格
- 减速器选型指南
- 紧固件数量
- 预估总成本（约 1500 人民币）

### 3. 3D 打印模型

**推荐打印参数：**
- 材料：PLA Basic 或更好
- 层高：0.18mm
- 填充率：35-60%（结构件）、20%（外观件）
- 支撑：按需添加

**注意：一些用于和联轴器连接的孔洞（M2.5）可能偏小，请按照你购买的联轴器孔径考虑是否要扩孔到 M3。**

### 4. 组装

按照 [Assembly Guide.md](./Assembly%20Guide.md) 进行分步组装：
- 组装顺序：从上到下。J1 → J2 → J3 → J4 → J5 → J6 → EE
- 紧固件规格
- 接线
