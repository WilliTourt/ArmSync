# ArmSync 六轴机械臂 IK 模型

## 坐标系

- **X+** = 人的前方
- **Y+** = 人的左方（左臂）  
- **Z+** = 人的上方（朝天）

## 关节链（从基座到末端）

| 关节 | 轴方向 | 到下一个轴的距离 | 对应人体 |
|------|--------|-----------------|---------|
| J1 | Y+ | 121mm → J2 | 大臂屈伸 |
| J2 | X+ | 160.985mm → J3 | 大臂外展内收 |
| J3 | Z- | 103.2mm → J4 | 大臂扭转 |
| J4 | Y+ | 95.0mm → J5 | 肘关节屈伸 |
| J5 | Z- | 90.519mm → J6 | 前臂扭转 |
| J6 | Y+ | 143.247mm → 夹爪 | 腕关节俯仰 |

零位姿态：手臂自然下垂（整条手臂指向Z-）时，所有电机转轴朝向为上表的“轴方向”。**J1特殊情况：**不管机械臂在不在零位姿态，J1转轴都是朝向Y+的，因为J1电机和基座是硬连接的。

### 旋转运动范围

注意，旋转正方向是遵循右手螺旋定则，大拇指朝向电机轴的方向，逆时针方向转就是正方向。运动范围的±指的是基于零位的。

| 关节 | 轴运动范围(deg) |
|------|--------|
| J1 | ±90 |
| J2 | -22.5~+125 |
| J3 | ±90 |
| J4 | -122~0 |
| J5 | ±90 |
| J6 | ±90 |

## Jetson 关键点映射

Jetson 以 **J2 轴Shoulder位置为原点**，输出 4 个关键点：

| Jetson 关键点 | 对应关节轴 | 说明 |
|-------------|-----------|------|
| Elbow | J4 | 肘的位置 |
| Wrist | J6 | 腕的位置 |
| Index | — | 食指（不要这个了） |
| Thumb | — | 拇指（也不要这个了） |

## J1 的处理

我们还是拿J1当原点，但是从NormalizeTask来的数据，Y轴一律应该加上121mm。
